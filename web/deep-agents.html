How deep research converges over days

  1. Cycle N — Each stream agent loads full telemetry, runs stream-specific statistical probes (not one-shot charts), and attaches evidence to hypotheses.
  2. Confidence accumulates — Re-running every 10–60 min adds evidence; confidence rises; status moves proposed → testing → supported → converged.
  3. Coordinator pass — Detects multi-stream agreement (e.g. wind gradient + leader foiling), scores novelty, promotes top insights to the board below.
  4. Novelty — Insights that combine streams or show large effect sizes rank higher; duplicates are suppressed.
  5. Stop condition — --until-converged 5 or run for days until insight board stabilizes.

Implementation in this repo

      
# One research cycle (all 3 streams + coordinator)
python scripts/run_deep_agents.py

# Every 10 minutes, for days
python scripts/run_deep_agents.py --watch --interval 600

# Stop when 5 hypotheses have converged
python scripts/run_deep_agents.py --until-converged 5 --interval 300

# API
curl -X POST http://127.0.0.1:8000/api/deep/run-cycle
